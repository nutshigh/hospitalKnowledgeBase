Chat 请求数据流

用户发送消息
      │
      ▼
┌─────────────────┐
│ 1. 加载上下文     │  ← 根据 chat_type:
│                  │     • "report": 从 DB 读取该报告的结构化数据
│                  │     • "general": 可选，用户最近报告摘要
└────────┬────────┘
         ▼
┌─────────────────┐
│ 2. 知识库检索     │  ← 将最近 N 轮对话 + 当前消息作为 query
│                  │     POST /api/v1/knowledge/internal/search
│                  │     返回 Top-K 医学知识
└────────┬────────┘
         ▼
┌─────────────────┐
│ 3. 构建 Prompt   │  ← System: 角色设定 + 报告数据 + 知识上下文
│                  │     Messages: 历史对话 + 当前消息
└────────┬────────┘
         ▼
┌─────────────────┐
│ 4. LLM 流式生成  │  ← 调用 LLM (Ollama API, stream=true)
│                  │     SSE 逐 token 推送给前端
└────────┬────────┘
         ▼
┌─────────────────┐
│ 5. 保存对话记录   │  ← 用户消息 + AI 回复写入 chat_message 表
└─────────────────┘
