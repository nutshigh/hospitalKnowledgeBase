错误处理 & 边界情况

Chat 模块的异常场景处理策略

场景 处理方式
LLM 调用超时 / 报错 SSE 推 error 事件，前端显示 "AI 响应失败，请重试"。已接收的部分 token 不入库
知识库检索无结果 不带知识上下文调用 LLM，依赖报告数据 + LLM 自身知识回答。记录 knowledge_miss 日志
SSE 连接中断 前端 EventSource 自动重连；重连时检查消息是否已入库，避免重复展示
未关联报告时提问报告相关问题 System prompt 中说明"用户无当前报告"，LLM 引导用户先上传报告
用户上传了报告但解析未完成 报告数据为空时提示"报告正在解析中，完成后可获取更精准的解读"
对话过长超出 LLM 上下文窗口 保留最近 20 轮对话 + 总结早期对话摘要，保持 token 不超限
医院数据库连接失败 仅影响该医院用户，返回 503 并提示稍后重试
并发流式请求 同一会话同时只能有一个活跃请求，新请求返回 429
