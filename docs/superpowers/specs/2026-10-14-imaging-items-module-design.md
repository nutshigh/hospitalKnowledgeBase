## 背景与诉求

报告中的影像类结果（心电图/CT/彩超等）目前只以自由文本躺在 `report_info.conclusion_text`
（报告详情页"总检建议与结论"卡片），没有结构化视图。用户希望新增一个模块：读取影像类结果，
按 **11 项检查**归位，每项给 **红/黄/绿** 三级，前端独立呈现（与指标列表/检查项列表形态区分），
且**有的项分男女**。

原始想法"解析 conclusion_text 原文 + 部位词匹配"经 v1 spec 与两轮 77 份存量语料探针
（2026-10-14）验证后修订为 **v2：结构化结论条目 ∪ 原文收紧扫描（双源并集）**。

### v2 探针结论（v5 收紧扫描，2026-10-14）

对原文侧加 6 类过滤后（见下）：
- "原文多出"的项已基本全是**条目真漏掉的真实发现**：心脏 7/7 真、心电图 6/6 真、
  甲状腺 4/4 真、颈动脉 3/3 真、胸部CT 5 条中 4 真、乳腺/子宫真。
- 残余噪声仅剩 6~8 处（已知类别，见"已知残留噪声"），可逐类收口。
- 条目侧反向补上原文漏扫的 10 处（004-6/25/58/59/65 等）。
→ 结论：**条目（精确）+ 原文收紧扫描（补漏）取并集** 是当前最优解；纯条目会漏 P6，
纯原文会引入 P1-P3。

### 替代路线评估记录（2026-10-14，结论：均不如 v2）

| 路线 | 否决理由 |
|---|---|
| 只用结构化条目 | 实测漏报真实可见发现（P6）；前端与结论区自相矛盾 |
| 原文裸扫（v1） | P1-P4 实测噪声（正常句 28 处、科普跨器官 24 份、条件句假红 9 条） |
| LLM 单次分类（解读 worker 挂接 + 存量回填） | ① 触碰解读 worker（最敏感链路，违背"不影响适配进度"）；② 结果随每次重跑漂移，与项目"确定性/基线"文化冲突；③ 77 份存量需 ~40-80 分钟 GPU 回填 + 新列迁移；④ LLM 自身有漏（P6 即 LLM 漏检），不解决覆盖问题 |
| 全报告文本/影像章节 | 抽取适配成本高（用户已排除）；结论段对多数医院已含检查综述/分科小结，增量有限 |
| 前端计算 / 落库预存 | 前端不可测（纪律要求）；落库新增列需三处迁移且无精度收益，按需可后补 |

**v2 代价声明**：过滤词表随新医院格式增长（集中单文件、审表可枚举收敛）；红与胸部X片
当前语料基本不亮；残留噪声需审表逐类收口——相对新管线/回填/漂移风险，这是最小代价。

## 需求确认（2026-10-14，v2 修订后）

1. **数据源（双源）**：
   - 源A：最新 completed 解读的 `indicator_judgment(source='conclusion')`（item_name + color_level）；
   - 源B：`report_info.conclusion_text` 原文收紧扫描；
   - 每项级别 = 两源取高（red > yellow > green）。
2. **实现位置**：后端纯函数 `build_imaging_items(conclusion_text, gender, entries)`；
   `GET /reports/{id}` 响应**纯追加** `imaging_items` 字段（旧字段不动）。
3. **黄**：任一源命中部位词 → 对应项标黄；源B 必须过 6 类过滤（核心：建议行不判黄、
   化验类排除、表头/正常句/科普段不判黄）；胸部肺系默认归胸部CT（仅"胸片/正位/X线"归
   胸部X片）；头部限头颅/颅内/脑梗/垂体等；颈动脉须显式词（防"胆囊内膜"）。
4. **红（保守）**：条目 `color_level='red'` → 项红；原文守卫后红（`(建议|请|嘱)…
   强紧急词` 且**非条件句**）→ 项红，不新建项。当前语料预期近零触发。
5. **绿**：其余一律绿（含整份零命中：H004 45/49/62、H003 3）；`conclusion_text` 为空且
   无条目 → 前端卡片显示"未提取到结论"（不显示色块）。
6. **性别**：男 8 项 / 女 10 项 / gender 缺失 11 项；**后端按 gender 过滤后返回**。
7. **前端**：医生端 + 用户端报告详情页各新增"影像类结果分级"卡片：两列色块
   （红→黄→绿排序、同级保持接口固定顺序；名称 + 红黄绿圆点），不混入指标折叠列表、不可展开（不做点击看原文）。
8. **验收**：pytest 纯函数断言 + 离线审表（77 份已验收报告，**先给用户审，再动前端**）
   + 后端重启 curl 验证；不碰基线、不跑全量护栏（本改动不在护栏覆盖层）。

## 算法（双源并集，单遍）

```python
def build_imaging_items(conclusion_text, gender, entries):
    # entries: [(item_name, color_level), ...]  最新 completed 解读的 source='conclusion' 行
    levels = {item: "green" for item in ITEMS}

    # ---- 源A: 结构化条目 ----
    for name, lvl in entries:
        name = collapse_ws(name)                    # 折叠内部空白(T 波改变)
        if NORMAL.search(name): continue
        masked = LAB_MASK.sub("", name)
        for item in keyword_hits(masked):
            levels[item] = max_level(levels[item], lvl)   # red>yellow>green

    # ---- 源B: 原文收紧扫描 ----
    if conclusion_text:
        current = []
        for raw in conclusion_text.splitlines():
            line = collapse_ws(raw)
            if not line: continue
            if BOUNDARY.match(line): current = []
            if line.startswith(("建议", "请", "嘱")): continue      # 建议行不判黄
            if line_skip(line): continue                            # 表头/化验长行/TCD
            if not BOUNDARY.match(line) and len(line) > 60: continue
            clauses = split_clauses(line)                           # [。；;]
            if line.startswith("【"): clauses = clauses[:1]         # 括号行只取首句
            for c in clauses:
                if NORMAL.search(c): continue
                core = strip_list_prefix(c)
                if core.startswith(("如", "若", "一旦")): continue   # 条件建议句
                m = CUT.search(core)                                # 科普/建议标记
                if m:
                    if m.start() == 0: continue
                    core = core[:m.start()]                         # 首个标记处截断
                masked = LAB_MASK.sub("", SOXIN.sub("", core))
                for item in keyword_hits(masked):
                    levels[item] = max_level(levels[item], "yellow")
                    current.append(item)
            # ---- 源B 红（保守 + 条件句守卫） ----
            if RED.search(line) and not COND.search(line) and current:
                for item in current: levels[item] = "red"

    return gender_filter(levels, gender)   # 男8/女10/NULL 11, 固定顺序
```

## 源B 过滤细则（实现终稿，词表为数据常量）

> 2026-10-14 审表收敛后的最终规则，与 `backend/app/modules/report/imaging_items.py` 一致；
> 括号内编号为审表实测案例。

1. **检查表头跳过**（防 P2）：
   - `【…】` 内文以检查词**结尾**（允许结尾括号组，如 `常规心电图检查(十二通道)`）：
     `彩超|B超|超声|检查|心电图|CT|核磁|DR|正位|摄片|摄影|费|四项|功能|血流图|多普勒|`
     `TCD|平扫|扫描|增强`（003-26 `【腰椎L3-S1/胸部低剂量螺旋CT平扫】`）；
   - 去掉行首 `★◆●○*▼►▶▍①-⑩` 后为**冒号标题行**时，仅当冒号前文本以
     "检查词/提示"尾词结尾才跳过（`心脏彩超:`/`本次体检心电图检查提示:` → 跳；
     `*心电图提示J点上抬:` → 发现行保留，2026-10-14 用户审表修）；
   - 去掉行首装饰后**以检查词结尾**的裸表头行（≤45 字；003-28 `◆甲状腺(甲状旁腺及颈部
     淋巴结)彩色多普勒超声检查`）；
   - `[一二三…]+、…(室|科|区):?`（如"二、心电图室:"）；
   - 含 `经颅多普勒|颅内多普勒|TCD` 的行（TCD 不属 11 项；004-68）。
   - **反例保护**：`1、彩超-二、三尖瓣少量反流`（内文含检查词但不在结尾）→ 发现行，不跳。
2. **正常句跳过**（防 P1）：
   - 子句级 `NORMAL`：`未见异常|未见明显异常|未见明显|无明显异常|无异常|未见异常回声|未见占位|
     未见肿大|正常范围|大致正常|正常心电图|无殊|未见异常信号|均在正常|测值正常|正常大小|
     未见明显结构|未见明显病变|未见明确异常|功能正常|均正常|阴性|弃检|未检|放弃|
     显示不清|显示欠清|显示欠佳`（003-30 `手术史`/`前列腺放弃`/`胰腺显示不清`）；
   - `窦性心律`（后不接 不齐/过缓/过速/缓慢/偏）视为正常：从子句删除后再扫其余文本
     （保 `窦性心律不齐/过缓` 仍命中）。
3. **化验行处理**（防 P3）：
   - 强化验标记行（`血脂|血糖|血尿酸|肌酐|尿素氮|载脂蛋白|甲胎蛋白|癌胚抗原|糖类抗原|
     FPSA|TPSA|同型半胱氨酸|铁蛋白|烯醇化酶|胃泌素|肌酸激酶|淀粉酶|脂肪酶|乳酸脱氢酶|
     转氨酶|胆红素|白蛋白|球蛋白`）且行长 >30 → 整行跳过（004-76 肌酸激酶科普）；
   - 其余情况用 LAB 遮蔽表删词后匹配（保 `肝功能异常；肝囊肿` 的"肝囊肿"仍命中；
     004-2 `乙型肝炎表面抗体` 不得命中肝）。
4. **长句截断**（防 P3，核心）：
   - 子句在**首个科普/建议标记**处截断，仅扫标记之前文本（**无论句长**；标记在句首则整句弃）；
   - 非编号行长行（>60 字）整行跳过；
   - 标记表（`CUT`）：`是指|可见于|常见于|多见于|发病率|原因|所致|解释|多数|少数|患者|病人|
     人群|风险|机制|作用|遗传|症状|治疗|预防|表现|导致|临床|建议|复查|随访|随诊|就诊|咨询|
     注意|饮食|运动|平时|如果|若|一旦|如需|可致|易患|典型|一般情况|偶然发现|无症状|需要|
     处理|办法|方法|门诊|检测|测定|试验|证实|表明|密切相关|包括|医生|生活质量|危险因素|
     增高|降低|升高|疾病|中耳|鼻炎|鼓膜|定期|避免|保持|加强|控制|减轻|摄入|食用|服用|
     手术史|必要时|诊治|见于|耳穴|穴位|检查|监测`；
   - **例外**：`检查` 后接 `提示/发现/所见/结果/显示/可见` 时不作截断点（报告方发现引导语：
     `本次检查发现【双侧颈动脉内-中膜粗糙】`）；`监测` 紧跟 `动态心电图` 时不作截断点
     （004-46 `2.监测动态心电图1.窦性心律2.偶发房性早搏…` 要判黄）。
5. **行内结构规则**（审表新增）：
   - 以 `【` 开头的行**只取首句**（其后为科普解释块；003-28 `血栓脱落进入颅内血管`、
     004-83 尿蛋白科普不判黄）；
   - 子句以 `如/若/一旦` 开头 → 条件建议句，不判黄（004-24 `如胸部CT或胸片发现肺结节…`）。
6. **条件句守卫（仅红用）**：`RED = (建议|请|嘱)[^。；\n]{0,25}(立即就医|立即就诊|尽快就诊|
   尽快就医|尽快手术|急诊|危急|切勿拖延|及时就诊|及时就医|及时复诊)`；
   `COND = (如果|若|如|一旦)[^。；]{0,40}(建议|请|嘱)` —— 命中 COND 的行不升红
   （审表实测：杀掉 H003-7/H004-5 两条"若…请及时复诊"假红后，77 份红色触发为 0）。
7. **空白折叠**：行/条目名先 `re.sub(r"\s+","")`（OCR 空格实例：`窦性 心律` /
   `1 0 、【 肝 胆胰脾 彩 超 】`）。

## 边界与错误处理

- `conclusion_text` 为空且无条目 → 后端返回 `[]`；前端显示"未提取到结论"。
- 整份零命中 → 全绿（用户口径：未提及一律绿）。
- 只有原文没有解读 / 只有解读没有结论文本 → 单源照样工作。
- 性别值为"N/A"/异常 → 按缺失处理（11 项）。
